Kalshi account
Off by default. The index feed always runs and saves its values to the data folder, but the page only uses it for pricing while this is ticked; if it fails it falls back to the learned gap.
  1. On kalshi.com open your profile, then API Keys, then Create New API Key.
  2. Copy the Key ID, and save the private key file Kalshi gives you (it is shown only once).
  3. Click Open keys folder and put that file in it. Do not paste the private key anywhere else, including chat.
  4. Paste the Key ID here and click Save and test.
The key can place real bets. Keep the file private. If it is ever exposed, delete that key on Kalshi's API Keys page.
Each mode can only bet the money you allocated to it. Only 15-minute crypto markets can be bought, always as a fill-or-kill order (it fills completely at your price or better, or not at all). Betting switches itself off when you change between real and demo.
